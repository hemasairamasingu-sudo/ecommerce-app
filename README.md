# E-Commerce Web Application

A full-stack E-Commerce Web Application that allows users to browse products, add products to a shopping cart, place orders, and track their orders. Admin users can manage products and orders through an admin dashboard.

## Project Overview

This project is developed as a full-stack web application using React.js for the frontend, Node.js and Express.js for the backend, and MongoDB for database management.

The application provides separate access for:

- Users
- Administrators

Users can purchase products and track their orders, while administrators can manage products and update order statuses.

## Features

### User Features

- User registration
- User login and logout
- JWT-based authentication
- Browse products
- Search products
- Filter products by category
- View product details
- Add products to cart
- Increase/decrease product quantity
- Remove products from cart
- View cart total
- Checkout
- Place orders
- View previous orders
- Track order status

### Admin Features

- Admin authentication
- Admin dashboard
- Add products
- View products
- Update products
- Delete products
- View customer orders
- Update order status
- Role-based access control
